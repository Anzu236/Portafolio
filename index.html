Caso de Estudio

Registro de Mediciones de Instrumentación

Proyecto personal desarrollado para aplicar conceptos de programación a una temática relacionada con mi experiencia profesional en instrumentación industrial.

Descripción

El proyecto consiste en una aplicación desarrollada para registrar y analizar mediciones relacionadas con instrumentación industrial.

Cada medición permite trabajar con información como el tag del instrumento, valor medido, unidad y límites operacionales.

Desafío principal

El principal desafío fue transformar una idea relacionada con el registro de información técnica en una solución programada capaz de almacenar las mediciones, analizarlas y presentar información útil.

También fue necesario establecer validaciones y reglas para determinar automáticamente el estado de una medición según sus límites.

Solución propuesta

Desarrollé una aplicación en JavaScript que permite registrar mediciones y trabajar posteriormente con la información ingresada.

El sistema compara cada valor con sus límites operacionales y determina automáticamente si se encuentra en estado NORMAL, ALARMA BAJA o ALARMA ALTA.

También permite consultar mediciones, buscar instrumentos mediante su tag, identificar condiciones de alarma, generar resúmenes y obtener estadísticas.

Herramientas utilizadas

HTML5 CSS JavaScript Visual Studio Code Git GitHub GitHub Pages

Habilidades técnicas aplicadas

Durante el desarrollo apliqué estructuras condicionales, ciclos, funciones, arreglos de objetos, validación de datos, búsqueda y filtrado de información.

También trabajé con lógica para cálculos, clasificación automática de estados y generación de estadísticas.

Principales aprendizajes

Este proyecto me permitió comprender mejor cómo organizar información utilizando estructuras de datos y cómo dividir un problema en funciones independientes.

También reforcé el uso de validaciones, condicionales y ciclos, además de trabajar con información registrada por el usuario para convertirla en resultados y estadísticas.

Uno de los aprendizajes más importantes fue poder relacionar conceptos de programación con una temática que conozco desde mi experiencia profesional.
