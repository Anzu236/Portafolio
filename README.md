## Proyectos destacados

### Registro de Mediciones de Instrumentación

Aplicación desarrollada en JavaScript para registrar y analizar mediciones asociadas a instrumentos industriales.

Permite trabajar con información como:

- Tag del instrumento
- Valor medido
- Unidad
- Límite mínimo
- Límite máximo
- Estado de la medición

La aplicación clasifica automáticamente las mediciones como:

- NORMAL
- ALARMA BAJA
- ALARMA ALTA

También permite realizar búsquedas, filtrar alarmas, generar resúmenes y obtener estadísticas.

**Tecnologías:** HTML, JavaScript, Git y GitHub.

Repositorio:

https://github.com/Anzu236/registro-mediciones-instrumentacion

Demo:

https://anzu236.github.io/registro-mediciones-instrumentacion/

### TaskFlow

Aplicación web desarrollada para la gestión de tareas.

Permite:

- Crear tareas
- Editar tareas
- Eliminar tareas
- Cambiar estados
- Establecer fechas límite
- Guardar información en LocalStorage
- Consultar datos desde una API externa

**Tecnologías:** HTML, CSS, JavaScript, LocalStorage, Fetch API.
